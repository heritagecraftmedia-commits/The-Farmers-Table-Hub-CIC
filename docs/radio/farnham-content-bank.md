# Farnham Radio — Content Bank

## Purpose

This is the working template for building a wide variety of safe, useful local radio content for The Farmers Table / Farnham Community Hub.

The operator should never need to remember the whole system. Pick a category, add the item, check the expiry date, and mark it Ready when the audio has been produced.

## Content record

For every item keep:

- **Name:** clear name of business, venue, organisation, show or feature
- **Category:** one of the categories below
- **Area:** Farnham, Farnham villages, Surrey, Hampshire, or wider
- **Type:** Jingle / Advert / Community Notice / Event / Feature / Interview / Music / Station ID
- **Length:** 10s / 15s / 20s / 30s / 60s / other
- **Script:** approved words to be spoken
- **Audio:** final MP3/WAV filename or library location
- **Website:** official website if applicable
- **Contact:** phone/email if approved for broadcast
- **Start date:** when it may begin playing
- **Expiry date:** when it must stop playing
- **Frequency:** light / normal / high
- **Status:** Idea / Script Needed / Recording Needed / Edit Needed / Ready / Retired
- **Notes:** anything the next operator needs to know

## Suggested advert lengths

Very short reminder or sponsor tag.

Simple local notice.

### 30 seconds
Standard local advert.

### 60 seconds
Feature-style promotion or detailed community announcement.

## Rotation rules

Do not simply play the same six adverts repeatedly.

Aim for a balanced rotation across:

1. Food & farming
2. Local businesses
3. Community organisations
4. What's On
5. Makers & heritage
6. Station information

Where possible, avoid putting two adverts from the same category back-to-back.

## Safety and accuracy check

Before an item is marked **Ready**:

- Confirm the business/organisation name.
- Check the address if one is spoken.
- Check website spelling.
- Check opening times if mentioned.
- Check prices/offers before broadcasting.
- Check event date and time.
- Add an expiry date.
- Do not invent awards, claims, offers or facts.
- Prefer the organisation's official information for factual details.

## Simple operator workflow

**1. FIND** — Choose a category.

**2. ADD** — Enter the basic information.

**3. SCRIPT** — Write or approve the words.

**4. RECORD** — Produce the voiceover.

**5. EDIT** — Add music/SFX only when appropriate.

**6. CHECK** — Confirm facts and expiry date.

**7. READY** — Put the finished audio in the correct radio library category.

**8. SCHEDULE** — RadioDJ / Live365 handles the technical playback and rotation.

## Important principle

The Farmers Table radio content library is the **content control layer**. It does not replace RadioDJ, Live365, BUTT or the streaming technology.

The library tells people **what the station has, what it is for, whether it is ready, and when it should stop playing**.

The radio automation/broadcast systems handle **playing it**.
