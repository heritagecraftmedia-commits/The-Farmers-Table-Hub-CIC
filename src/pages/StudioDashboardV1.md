# Farmers Table Radio — Studio Dashboard V1

## Purpose

A simple staff-facing studio workflow for preparing radio slots. Live365 remains responsible for the actual broadcast and outside broadcasts. The Farmers Table dashboard manages the content library, playlists, jingles, adverts, programme slots and next-up queue.

## Presenter workflow

1. Sign in with a permitted staff/radio role.
2. Open today's radio slot.
3. Load a ready-made playlist or add items from the library.
4. Use one-click actions to add music, jingles, adverts and community notices.
5. Use **Add Next** for a listener request without disturbing the rest of the prepared slot.
6. See total duration and remaining time for the slot.
7. Reorder or remove items.
8. Save the slot/queue.

## Library categories

- Music
- Jingles / station IDs
- Adverts
- Community notices
- Interviews
- Recorded programmes
- Features

## Core controls

- Add
- Add Next
- Load Playlist
- Move Up
- Move Down
- Remove
- Clear
- Save Slot
- Preview

## Permissions

- Founder: full control
- Radio Manager: manage library, playlists, programmes and adverts
- Presenter/Staff: prepare today's slot, add/reorder items and cue the next item

## Broadcast boundary

The dashboard does not replace Live365 or BUTT. Live365/BUTT remains the broadcast path. The dashboard is the simple content-preparation and presenter control layer.
